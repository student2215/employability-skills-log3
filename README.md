# BSM24005 Employability Skills Log

A single-page employability skills log website for Ravensbourne University London (BSM24005 Contemporary Issues and Culture in Creative Industries, Task A3).

## How to publish on GitHub Pages

1. Create a new repository on GitHub (for example `employability-skills-log`). Set it to **Public**.
2. Upload every file in this folder, keeping the structure:
   - `index.html`
   - `style.css`
   - `images/library-research.png`
   - `images/digital-study.png`
3. Go to the repo's **Settings → Pages**.
4. Under **Source**, choose **Deploy from a branch**, select branch `main` and folder `/ (root)`, then **Save**.
5. Wait a minute, then refresh. Your live link appears at the top of the Pages settings, usually:
   `https://<your-username>.github.io/employability-skills-log/`

Paste that live link into your Word/PDF reflection submission and your BSM assessment cover sheet.

## Before you submit — edit these

- In `index.html`, replace `[Your Name]` and `[Student ID]` in the header.
- Swap or add your own photos/screenshots in the `images` folder if you want more evidence (keep the same file names, or update the `src` paths in `index.html`).
